fedxss measurement harness

Produces the operational figures for Table 4.3. Run in the browser you intend to report, with other tabs closed. Memory figures require Chrome started with --enable-precise-memory-info; without it Chrome rounds performance.memory heavily and the number is not worth reporting.

If the model fails to load, this page is probably open via file://, which cannot fetch. Serve the directory instead: python3 -m http.server 8765 then open http://localhost:8765/bench.html. Alternatively pick the file manually below.
